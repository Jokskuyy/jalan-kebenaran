# AGENT/16 Starter Cases

> **TRAINING DATA — SYNTHETIC.** Semua organisasi, orang, transaksi, SOP internal, dan angka operasional di folder ini bersifat fiktif untuk latihan. Metadata regulasi publik harus diverifikasi kembali dari sumber resmi sebelum dipakai. Materi ini bukan nasihat hukum atau finansial.

- `regularag/` mendukung mission W01–W08.
- `invoiceops/` mendukung mission W09–W13.
- `portfolio/` mendukung packaging, interview, dan application sprint W14–W16.

Tidak ada data client, PII, credential, nomor rekening, NPWP, alamat, email, atau nomor telepon.
